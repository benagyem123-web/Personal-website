BERNARD AGYEMANG PERSONAL WEBSITE - GITHUB PAGES

1. Create a new GitHub repository.
2. Upload index.html and the entire images folder.
3. Make sure index.html stays in the repository root.
4. Go to Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the main branch and the / (root) folder, then Save.
7. GitHub will provide the website address.

IMPORTANT:
- Do not rename the images folder unless you also change the paths in index.html.
- Keep image filenames exactly as supplied.
- This website uses only local files: HTML, CSS, JavaScript and JPG images. No external framework is required.
